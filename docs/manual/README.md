# Rein Manual

Updated for Rein v0.27.6.

Rein is a local-first, self-adaptive memory system for AI agents. It provides a
single Rust binary with CLI, MCP, REST, GUI, hook, and record-only proxy
surfaces over one local SQLite memory store.

## Repository Context

The manual is written for GitHub Markdown and explains stable public behavior.
The root [README](../../README.md) remains the quick project entry point. The
manual chapters provide longer explanations, while reference material under
`docs/reference/` is intended for command tables, API inventories, configuration
keys, and citations.
