# Code of Conduct

This project adopts the **[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)**
as its code of conduct. By participating in this project — through issues,
pull requests, discussions, or any other channel — you agree to abide by its
terms.

The full text of the Contributor Covenant 2.1 is available at the link above
and is incorporated here by reference.

## Scope

This Code of Conduct applies within all project spaces — the GitHub
repository, issue tracker, pull requests, discussions, and any official
communication channels — and also when an individual is officially
representing the project in public spaces.

## Reporting

If you experience or witness unacceptable behavior, please report it through
one of the following channels:

- **Private security advisory** (preferred for anything sensitive):
  <https://github.com/lyr1cs/rein/security/advisories/new>

  GitHub's security advisory system provides a private, maintainer-only
  channel even though the repository itself is public. Use this for any
  report you do not want visible to the wider community.

- **Direct contact**: open an issue and request a private channel; a
  maintainer will reach out to continue the conversation off-list.

All reports will be reviewed and investigated promptly and confidentially.
The maintainers are obligated to respect the privacy and safety of the
reporter of any incident.

## Enforcement

Project maintainers are responsible for clarifying and enforcing the
standards of acceptable behavior described by the Contributor Covenant 2.1
and will take appropriate and fair corrective action in response to any
behavior they deem inappropriate, threatening, offensive, or harmful.

Maintainers have the right and responsibility to remove, edit, or reject
contributions that are not aligned with this Code of Conduct, and will
communicate reasons for moderation decisions when appropriate.
